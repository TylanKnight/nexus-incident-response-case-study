# Incident report template

Blank template for a future authorized investigation or clearly labeled synthetic exercise.

## Identification and scope

- Case ID and report version:
- Author and date:
- Environment: real authorized investigation / synthetic lab:
- Authority, affected systems and exclusions:
- Business impact established by evidence:

## Summary

Describe what the evidence supports. Separate suspected activity from confirmed findings.

## Evidence and methods

List evidence-register IDs, collection methods, tools actually used, integrity checks, time normalization and known gaps.

## Timeline

| Original timestamp and offset | Normalized UTC time | Evidence ID | Observed event | Interpretation and uncertainty |
|---|---|---|---|---|
| | | | | |

## Findings

For each finding, state the supporting evidence, competing explanation, corroboration and limitation. Do not label a person as the actor merely because an account is named.

## Response and recovery

Record actions actually performed, who approved them, time, effect, evidence impact, rollback and validation. Put proposed actions in a separate list.

## Remediation and unresolved questions

| Action or question | Owner | Due date | Acceptance evidence | Status |
|---|---|---|---|---|
| | | | | |

## Conclusion

State the supported scope and remaining uncertainty. Include no unmeasured performance claims.
